# Balanceamento REDOX

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22119244.svg)](https://doi.org/10.5281/zenodo.22119244)

Recurso digital procedimental para apoiar o balanceamento de equações químicas pelo método de oxirredução. O jogador revisa conceitos e realiza, em sequência, a identificação dos elementos, as variações de NOX, os agentes oxidante e redutor e o ajuste dos coeficientes.

## Acesso

- Jogar on-line: https://yurig4.github.io/Redox/
- Código e arquivos da versão web: https://github.com/yurig4/Redox

O jogo foi desenvolvido no Construct 3 e exportado como aplicação web em tela cheia, orientação horizontal e com suporte a funcionamento offline.

## Conteúdos e dinâmica

- coeficientes e índices;
- número de oxidação;
- oxidação e redução;
- agentes oxidante e redutor;
- balanceamento de equações por oxirredução.

## Execução local

Por utilizar recursos de aplicação web e armazenamento offline, o jogo deve ser servido por um servidor HTTP local. Depois, abra `index.html` pelo endereço fornecido pelo servidor.
